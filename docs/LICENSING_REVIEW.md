# Licensing review (pre-release)

> Not legal advice. This is the engineering inventory a lawyer or licensing contact needs; confirm the action items before selling.

## What does NOT ship (deliberately)

| Item | Why | Action before bundling or auto-downloading |
|---|---|---|
| MDX-Net vocal models (`Kim_Vocal_2.onnx`, `UVR-MDX-NET-Voc_FT.onnx`) | Community-trained (UVR project). No explicit licence for **commercial redistribution** of the weights; training data is undocumented | ⚠️ Keep "user installs it" **or** get written permission from the model authors **or** train/licence your own model. Don't put them in the installer or a download button until this is resolved |
| Demucs weights | Not used. Code is MIT, but weights trained on MUSDB have research-only training data | n/a |
| GPL code (e.g. Rubber Band) | Avoided on purpose: Signalsmith (MIT) is used instead | ✅ |

## Product-claim checks

- Character scores, breathiness and GHOST MATCH are described in the UI and docs as **heuristics / measured similarity**, not emotion detection or perceptual guarantees. Keep marketing copy consistent with that.
- Search is described as keyword mapping, not AI understanding. The optional LLM interface is not shipped.
- Sampling responsibility: GHOSTCUT processes audio the user imports. A short line in the manual/EULA that users are responsible for having rights to their source material is recommended.

## Your own EULA

Add a simple EULA (licence grant, no redistribution, no warranty, sample-rights responsibility) to the installers before v1.0. Inno Setup can show it via `LicenseFile`, and the macOS pkg via `<license>` in `distribution.xml`.
